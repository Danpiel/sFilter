# sFilter

Аддон для World of Warcraft, который показывает нужные дебаффы на цели и баффы на себе и питомце, чтобы держать ротацию и не терять урон. Оригинал — Nils Ruesch и ALZA, обновление — Danpiel.

Поддерживаемые клиенты:

| Клиент | Interface |
|---|---|
| World of Warcraft: Forever | 16001 |
| Retail (Midnight) | 120100, 120105 |

## Установка

Папка аддона должна называться **`sFilter`**: `World of Warcraft\_forever_\Interface\AddOns\sFilter\sFilter.toc` (для retail — `_retail_`). Файлы `README.md`, `tests` и `.git` в игре не нужны, но и не мешают. Если раньше стоял DSFilter, удалите его папку: позиции групп перенесутся в sFilter автоматически.

## Что умеет

- **Группы иконок.** Стандартная раскладка повторяет старый sFilter: «Защита», «Баффы», «Дебаффы цели» и крупные «Проки». Группы можно добавлять, переименовывать, менять им размер иконок, отступы, число иконок в ряду, направление роста и прозрачность.
- **Перемещение и закрепление.** `/sf unlock` (или кнопка в настройках) показывает рамки групп: перетаскивайте левой кнопкой, правый клик открывает меню (закрепить группу, сбросить позицию, скрыть, показать неактивные). Закреплённую группу нельзя сдвинуть случайно. Есть сетка для выравнивания. Править код больше не нужно: позиции хранятся в SavedVariables.
- **Редактор иконок.** Добавление по ID, ссылке или названию заклинания. На одну иконку можно повесить несколько заклинаний, тогда показывается первое найденное. Можно выбрать, где искать ауру (на себе, на цели, на питомце, на фокусе), её тип (бафф или дебафф) и для каждого заклинания — чьи ауры считать: «Мои» (ваши и питомца) или «Все» (кнопка рядом с заклинанием). Ауры ищутся и по ID, и по названию, поэтому вне боя один ID покрывает все ранги заклинания. Для эффектов без какой-либо ауры есть режим «Показывать, пока идёт кулдаун» (подходит, если кулдаун равен длительности).
- **Экспорт и импорт.** Строка `!SF1!…` содержит весь профиль класса или только расположение групп. Импорт полностью проверяет данные: битая или чужая строка ничего не сломает.
- **Таймер, затухание и вспышка.** Таймер без ведущих нулей: меньше минуты — только секунды (`45`, `5`), дальше — минуты и секунды (`1:05`). За последние секунды (по умолчанию 2, настраивается в группе) иконка плавно гаснет, а не пропадает рывком. По желанию иконка вспыхивает, когда таймер заканчивается (опция группы). В бою у иконок контейнера аур Blizzard работает тот же таймер, но затухание и вспышка там недоступны: оставшееся время аддону не видно.
- **Стандартные наборы для Forever** собраны по базе Wowhead для Forever: все ранги каждого заклинания, руны (Искусство войны, Сабельный удар, Прилив крови и т. д.) и новые заклинания Forever (Печать ярости, Гнев карателя…). Только короткие боевые баффы, проки и дебаффы, без часовых баффов.
- **Чьи ауры считать по умолчанию.** Урон по цели (DoT, кровотечения) и дебаффы, которые помогают только вам (Кровоизлияние, Пронзание разума, Объятия вампира…), — «Мои». Остальные дебаффы цели (броня, проклятия, метки, правосудия, замедления, оглушения и другой контроль) — «Все». Сохранённые профили получают эти настройки один раз при первом входе после обновления; заклинания, добавленные вручную, сохраняют свои.
- **Вид как у EllesmereUI.** Окно настроек оформлено в стиле EllesmereUI: тёмные плоские панели, тонкие рамки, боковое меню страниц и один акцентный цвет (бронзовый в Forever, бирюзовый в retail).
- **Встраивание в EllesmereUI.** Если EllesmereUI установлен, настройки sFilter появляются в его панели отдельным разделом «sFilter» с вкладками «Иконки», «Группы», «Экспорт / импорт» и «Cooldown Manager», а цвет и шрифт берутся у EllesmereUI (в русском клиенте шрифт игровой, как и у самого EllesmereUI). `/sf` открывает настройки там; в бою панель EllesmereUI не открывается, и тогда открывается собственное окно sFilter.
- **ElvUI.** Если ElvUI загружен, иконки, окно настроек, кнопки, поля, чекбоксы, выпадающие списки и скроллбары оформляются в его стиле. `/moveui` в ElvUI заодно разблокирует и группы sFilter.

## Важно: бой, боссы, M+ и PvP

С Midnight (12.0) Blizzard скрывает от аддонов содержимое аур в бою, во время боя с боссом, в M+ и PvP-матчах (так называемые «secret values»). WoW: Forever работает на том же движке, и ограничение там тоже действует. Аддон видит, что аура есть, но не знает, какая это аура. Поэтому WeakAuras и старый sFilter в бою больше не работают.

sFilter решает это так:

1. **Баффы на вас и питомце, дебаффы на цели и фокусе** (основной сценарий) работают и в бою. Для них sFilter использует встроенный контейнер аур Blizzard (`CustomAuraContainer`): доверенный код Blizzard сам находит ауру по списку ID заклинаний и заполняет иконку, таймер и стаки sFilter. Внешний вид, размер и позиция остаются вашими, с ElvUI — в его стиле. Настраивать ничего не нужно.
2. **Остальное** (дебаффы на вас, баффы на цели) в бою работает, только если заклинание отслеживает встроенный **Cooldown Manager**: sFilter берёт его иконку и ставит в свой слот. Вне боя такие иконки работают как обычно.

Особенности:

- Контейнер сравнивает только ID, а в Forever у каждого ранга заклинания свой ID. Поэтому в стандартных наборах перечислены все ранги, а для своих иконок sFilter добавляет ранг, который знает персонаж, и запоминает ранги, увиденные на аурах вне боя.
- Кнопки контейнера нельзя менять, пока ауры секретные. Изменения размера или набора иконок, сделанные в бою, применятся сразу после боя. Перетаскивать группы можно и в бою.

Для Cooldown Manager (только для иконок из пункта 2): `/sf cdm` → «Включить Cooldown Manager» → «Открыть Cooldown Manager (/cdm)» → перетащите заклинания в **«Отслеживаемые баффы» (Tracked Buffs)**, в режиме редактирования поставьте видимость «Всегда» и включите «Скрывать неактивные». На вкладке «Cooldown Manager» в настройках видно, какие иконки работают в бою.

## Режим редактирования

`/sf unlock`, кнопка в настройках, режим редактирования Blizzard (Edit Mode) или `/moveui` в ElvUI разблокируют группы. Все иконки показываются как сработавшие, с идущим таймером и стаками, чтобы было видно, как будет выглядеть раскладка в бою.

## Команды

| Команда | Действие |
|---|---|
| `/sf` | открыть настройки |
| `/sf unlock`, `/sf lock`, `/sf toggle` | разблокировать или закрепить группы |
| `/sf export`, `/sf import` | экспорт и импорт настроек |
| `/sf cdm` | состояние Cooldown Manager |
| `/sf reset` | сбросить профиль класса к стандартному |

Аддон также есть в меню аддонов у миникарты: левый клик открывает настройки, правый — разблокирует группы.

## Файлы

| Файл | Назначение |
|---|---|
| `Core.lua` | старт, слэш-команды, общие утилиты |
| `Defaults.lua` | стандартные группы и наборы заклинаний для Forever и retail |
| `Profile.lua` | SavedVariables, проверка профилей, экспорт и импорт |
| `Serializer.lua` | сериализация строки экспорта (без `loadstring`) |
| `Tracker.lua` | поиск аур и обработка скрытых данных |
| `Display.lua` | группы, слоты, перемещение, сетка |
| `NativeAuras.lua` | показ в бою через контейнер аур Blizzard |
| `CDMBridge.lua` | связка с Cooldown Manager |
| `Skin.lua` | стандартный стиль и стиль ElvUI |
| `Options.lua` | окно настроек |
| `Ellesmere.lua` | раздел в панели настроек EllesmereUI |
| `Locales.lua` | английский и русский тексты |

## Тесты

`tests/` — мок WoW API и тесты, которые запускают аддон в обычном Lua 5.1 (через Python-пакет `lupa`): Forever, retail, ElvUI, английская локаль, скрытые ауры, Cooldown Manager, экспорт и импорт, перемещение групп, окно настроек, раздел в EllesmereUI.

```bash
python -m pip install lupa
python tests/run.py .
```
